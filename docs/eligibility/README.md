# Eligibility verification: private handling

This tracked directory is a **documentation-only placeholder**, not a secure document vault. Git ignore rules prevent common accidental additions but do not encrypt files or prevent forced commits. Keep student cards and official identity/eligibility documents outside the repository whenever possible.

## Private workflow

1. Confirm the organizer's eligibility requirements and approved private submission channel.
2. Obtain each team member's consent and collect only required evidence, such as a current student card or enrollment confirmation.
3. Store evidence in an encrypted, access-controlled local folder outside this checkout. If a temporary local staging folder is essential, use `docs/eligibility/private/`; all its contents are ignored, including nested files.
4. Use neutral filenames such as `member-01-enrollment.pdf`; do not embed student numbers, birth dates or other identifiers in filenames.
5. Redact unrelated details only where the organizer permits it. Do not publish scans, screenshots, identity numbers or document links in issues, commits, README files or the demo video.
6. Submit documents through the organizer's authorized private channel. Record status in the private team tracker and delete temporary copies according to the agreed retention period.

## Team completion checklist

- [ ] Organizer eligibility criteria and private channel confirmed.
- [ ] All members' consent and required evidence obtained.
- [ ] Authorized team reviewer checked current enrollment/eligibility.
- [ ] Evidence submitted privately and receipt verified.
- [ ] Temporary files removed when no longer needed.
- [ ] Staged files and Git history checked for accidental disclosure.

Do not fill this public checklist with personal details. No identities, student cards or eligibility claims are supplied by this repository. If a document was ever committed, ignoring or deleting it from the working tree does not remove it from Git history; restrict access and coordinate remediation before publishing.
